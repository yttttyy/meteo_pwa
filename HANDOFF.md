## Что это

Домашняя метеостанция на **ESP32-S3**: LCD2004 с большими часами в стиле AlexGyver
MeteoClock, датчики воздуха, RGB-подсветка, веб-интерфейс (PWA) во флеше.
Собрано **две физические станции**, они отличаются начинкой — см. ниже.

Язык общения с владельцем — русский. Комментарии в коде тоже русские.

## Рабочий цикл

**Правка страницы:**

1. Меняешь `web/index.html`.
2. Предпросмотр: `preview_start` по имени **meteo-web** (конфиг в `.claude/launch.json`,
   поднимает `.claude/serve.py` на порту 8767). Страница работает на моке, железо не нужно.
   Сценарии: `?mock=alarm`, `?mock=offline`, `?mock=ap`.
3. `python build_web.py` — пакует страницу в `INDEX_HTML_GZ`.
4. Компиляция (путь к CLI внутри Arduino IDE):

```
"C:/Users/Admin/AppData/Local/Programs/Arduino IDE/resources/app/lib/backend/resources/arduino-cli.exe" \
  compile --fqbn esp32:esp32:esp32s3:CDCOnBoot=cdc "C:/Users/Admin/Desktop/claude/meteo_pwa"
```

5. Заливка — по OTA через саму страницу (Настройки → Прошивка), USB не нужен.

**Размер важен.** Флеш занят на ~88%, свободно ~157 КБ. Страница отдаётся gzip'ом
(`handleRoot` ставит `Content-Encoding`), сейчас ~18 КБ в сжатом виде.
Ориентир — не раздувать больше ~22 КБ.

## Две станции

| | Станция 1 | Станция 2 |
|---|---|---|
| AHT21 (t°, влажность) | есть | **нет** |
| ENS160 | есть, питание 3.3 В | есть, питание **5 В** |
| MH-Z19C | есть | есть |
| DS3231 | есть | нет |
| Сенсорная кнопка | есть | **нет** |

Распиновка общая, в `config.h`. Ключевое: **GPIO43/44 не трогать** — это загрузочный
UART, MH-Z19C живёт на 15/16.

На станции 2 без AHT21 балл климата считается только по CO₂, TVOC и AQI — веса
не перенормируются, просто сумма становится 0.6.

## Что не доделано

- **Сравнение CO₂ и eCO₂ не проведено.** Ради него делались выгрузка `/export` и
  запись eCO₂ в историю. Цель — понять, можно ли выкинуть дорогой MH-Z19C и
  обойтись ENS160. Данные копятся, выводов нет.
- **Шина I2C подтянута к 5 В** из-за LCD-переходника, а ESP и ENS160 трёхвольтовые.
  ESP зажимает линии защитными диодами на ~4 В. Работает, но вне даташита.
  Правильно — преобразователь уровней либо свои подтяжки на 3.3 В.
- **Узлы-сателлиты** (`/data.nodes`) приходят, но в вебе не показываются.
- **Лист настроек на мобильной** растягивается на высоту сетки, снизу остаётся пусто.
  Косметика.
- `web/index.prev.html` — бэкап старой страницы, в гит не клался, лежит на диске.
  Старая версия и так есть в истории (коммит «Веб-интерфейс на плитках»).

## Грабли, на которых уже обожглись

**Железо**

- `GPIO43/44` = U0TXD/U0RXD. Повесишь туда UART — получишь `Download timeout!` и `CCCCCC`.
- Эмиттеры транзисторов подсветки обязаны быть на земле. При обрыве напряжение на
  ногах «есть», но ток идёт только через мультиметр — измерения выглядят правдоподобно.
- Контраст LCD: `VDD − V0 ≈ 4.5 В`, то есть **V0 около 0.5 В**. Окно узкое, при V0=5 В
  экран абсолютно чистый. Пины 2 и 3 соседние — каплю припоя между ними ловили.
- Негативный экран (RGB on Black) без подсветки не читается в принципе.
- CGRAM забита: 8 слотов. Слот 3 свободен **только** в шрифте «палки», туда и
  уходит стрелка тренда; в скруглённом он занят под `CB`, там ASCII `^`/`v`.
- `0xFF` на кириллическом ROM — не сплошной блок, освобождать CGRAM им нельзя.

**Веб**

- Атрибут `hidden` слабее классов вроде `.pal{display:flex}`. В CSS стоит
  `[hidden]{display:none!important}` — без него скрытое остаётся видимым.
- Абсолютно позиционированный элемент без `top/left` встаёт на *статическую* позицию,
  то есть в конец сетки. Лист раскрытия из-за этого стартовал из правого нижнего угла.
- Браузер агрессивно кеширует `index.html` и `dev-mock.js`. Поэтому `.claude/serve.py`
  отдаёт `Cache-Control: no-store`.
- Там же: сервер обязан быть `ThreadingHTTPServer`. На однопоточном `TCPServer`
  keep-alive вешает все последующие запросы — выглядит как «страница не грузится».

**Инструменты**

- Таймеры и `requestAnimationFrame` в панели предпросмотра идут неравномерно.
  Мерить анимации через `setTimeout` бесполезно — врёт. Надёжно только через
  Web Animations API: `el.getAnimations()`, `pause()`, `currentTime`.
- `build_web.py` печатает в консоль Windows (cp1252) — вывод уже переведён на utf-8,
  но если добавлять печать, помни про это.

## Принципы, о которых просил владелец

- Балл климата считает **только прошивка** (`climate.h`) и отдаёт в `/data.clim`.
  В JS дублировать формулу нельзя — LCD и веб обязаны показывать одно и то же.
- Пороги зон живут в станции (Preferences + `/cfg?thr_*`), не в localStorage.
- Бэкенд при правках интерфейса не трогать: набор роутов и параметров зафиксирован.
